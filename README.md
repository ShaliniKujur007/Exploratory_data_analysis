# Exploratory_data_analysis# Electoral Bond Analysis (2019–2024)

## 📌 Project Overview

This project performs an **Exploratory Data Analysis (EDA)** of electoral bond transactions in India from **2019 to 2024**. The analysis focuses on understanding purchasing patterns, funding trends, purchaser behavior, political party-wise contributions, and other insights derived from the available electoral bond data.

The project uses **Python-based data analysis and visualization techniques** to clean, process, analyze, and interpret more than **18,870 bond transactions**.

## 🎯 Objectives

* Analyze electoral bond transactions and funding patterns.
* Identify major bond purchasers and their contribution trends.
* Study political party-wise funding patterns.
* Examine transaction amounts across different time periods.
* Identify the highest-value transactions and major contributors.
* Generate meaningful visualizations to understand the data more effectively.

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data cleaning, manipulation, and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Analysis and documentation

## 📊 Analysis Performed

The notebook includes analysis of:

* Data cleaning and preprocessing
* Missing values and duplicate records
* Transaction amount distributions
* Purchaser-wise contribution patterns
* Political party-wise funding
* Time-based transaction trends
* Top purchasers and highest-value bonds
* Frequency and value of transactions
* Comparative visual analysis

## 📈 Visualizations

The project contains multiple visualizations to present the findings clearly, including:

* Bar charts
* Count plots
* Distribution plots
* Histograms
* Box plots
* Time-series visualizations
* Party-wise and purchaser-wise comparisons

These visualizations help identify trends and patterns that may not be immediately visible from the raw data.
